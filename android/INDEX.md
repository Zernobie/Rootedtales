## 🎯 Common Scenarios

### Scenario 1: First Time Setup

**Goal:** Get started with the package

**Steps:**
1. Read ANDROID_PACKAGE_SUMMARY.md
2. Read README.md
3. Install prerequisites (DEPLOYMENT_GUIDE.md Section 1)
4. Follow BUILD_COMMANDS.md → Installation Commands

### Scenario 2: Building Release AAB

**Goal:** Create signed AAB for Play Store

**Steps:**
1. Review BUILD_COMMANDS.md → Keystore Creation
2. Follow BUILD_COMMANDS.md → Release Build Commands
3. Verify output location
4. Test on device (optional)

### Scenario 3: Creating Store Assets

**Goal:** Prepare graphics for Play Store

**Steps:**
1. Read PLAY_STORE_ASSETS.md in full
2. Gather brand materials
3. Create app icon (512×512)
4. Create feature graphic (1024×500)
5. Take 8 screenshots
6. Enhance and frame screenshots

### Scenario 4: Submitting to Play Store

**Goal:** Upload and submit app

**Steps:**
1. Use DEPLOYMENT_CHECKLIST.md
2. Complete all checklist items
3. Follow DEPLOYMENT_GUIDE.md → Section 9
4. Upload AAB
5. Complete store listing
6. Submit for review

### Scenario 5: Troubleshooting Build Issue

**Goal:** Fix build error

**Steps:**
1. Check error message
2. Review DEPLOYMENT_GUIDE.md → Troubleshooting
3. Try BUILD_COMMANDS.md → Maintenance Commands
4. Clean and rebuild
5. If persists, contact hub@xenwinx.com

### Scenario 6: Updating the App

**Goal:** Release new version

**Steps:**
1. Review DEPLOYMENT_GUIDE.md → Update Process
2. Update version numbers
3. Build web assets
4. Sync Android
5. Build new AAB
6. Upload to Play Console
