# Google Play Store Assets - Rooted Tales

## 📱 Required Graphics & Marketing Materials

---

## 1. App Icon

**Specifications:**
- **Size:** 512 x 512 px
- **Format:** 32-bit PNG with alpha channel
- **File size:** Max 1 MB
- **Design:** Must match the launcher icon

**Design Guidelines:**
- **Primary element:** Red panda (Akai) silhouette
- **Background:** Forest green (#22c55e) or gradient
- **Secondary element:** Tree or forest motif
- **Style:** Friendly, child-appropriate, colorful
- **Text:** App name optional, but keep minimal

**Color Palette:**
- Primary: #22c55e (Green)
- Secondary: #f97316 (Orange - red panda)
- Accent: #1a472a (Dark green)
- Highlights: #86efac (Light green)

---

## 2. Feature Graphic

**Specifications:**
- **Size:** 1024 x 500 px
- **Format:** JPG or 24-bit PNG (no alpha)
- **File size:** Max 1 MB

**Design Elements:**
```
[Left side]                    [Center]                    [Right side]
─────────────────────────────────────────────────────────────────────
Akai character     →     "Rooted Tales" logo    →    Book/tree icons
illustration             with tagline                  or forest scene
                         "Interactive Stories
                         for Young Readers"
```

**Content:**
- App logo/name prominently displayed
- Tagline: "Interactive Children's Books"
- Feature Akai (red panda character)
- Background: Forest theme with subtle green gradient
- Include 2-3 book covers or character icons
- Style: Colorful, inviting, child-friendly

**Text to include:**
- "Rooted Tales"
- "12 Interactive Books"
- "4 Magical Themes"
- "Ages 4-10"

For each screenshot:
- Add a colored frame/border matching app theme

- Display unlocked content (not locked/grayed out)
- Use the most visually appealing theme (Forest or Sunset)

- **Format:** MP4

**Video Structure:**

