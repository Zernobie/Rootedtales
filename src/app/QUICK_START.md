# 🚀 Rooted Tales - Quick Start

## ⚡ 3 Steps to Get Running

### Step 1: Restructure (2 minutes)

**Windows:**
```powershell
.\RESTRUCTURE.ps1
```

**macOS/Linux:**
```bash
chmod +x RESTRUCTURE.sh
./RESTRUCTURE.sh
```

### Step 2: Install & Run (3 minutes)

```bash
npm install
npm run dev
```

### Step 3: Open Browser

Visit: **http://localhost:5173**
