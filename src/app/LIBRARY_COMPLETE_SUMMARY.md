### **Smart URL Generation**:
All books use programmatic URL generation for efficiency:

```typescript
// Standard pattern (most books)
pages: Array.from({ length: PAGE_COUNT }, (_, i) => 
  `https://cxvvicjtyhkynedezmag.supabase.co/storage/v1/object/public/books/BOOK_NAME/page-${String(i + 1).padStart(3, '0')}.png`
),
```

### **Special Cases**:

**Book 6 (Sea Otter)** - Double dots for pages 10-61:
```typescript
pages: Array.from({ length: 61 }, (_, i) => {
  const pageNum = String(i + 1).padStart(3, '0');
  const extension = i >= 9 ? '..png' : '.png';
  return `https://.../page-${pageNum}${extension}`;
}),
```

**Book 11 (Wise Owls)** - URL differs from title:
- **Title**: "Akai's lessons with The Wise Owls" (with apostrophe)
